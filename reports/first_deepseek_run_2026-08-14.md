# CareerPilot 第一次 DeepSeek V4 Pro 真实运行

日期：2026-08-14

## 运行配置

- 模型：`deepseek-v4-pro`
- Thinking mode：关闭
- 输入：匿名职业画像 + 阿里巴巴 2027 届产品经理公开岗位摘要
- 未发送：姓名、手机号、邮箱、真实简历

## 运行结果

模型判断：`stretch`，置信度 `medium`。

已确认：

- 2027 届毕业时间方向满足
- 本科学历满足
- 金融专业与经济、管理类方向相邻
- 沟通自评为 4/5，可作为方向性优势

尚未提供证据：

- 产品用户研究或 PRD
- SQL、Excel、Python 分析作品
- Axure 或 Figma 原型
- 结果导向的真实行为案例

## 与离线基线的区别

离线基线判断为 `likely_apply / low confidence`；V4 Pro 判断为 `stretch / medium confidence`。V4 Pro 更谨慎，认为基础资格满足不代表已具备可竞争的产品证据。这个调整合理。

## 发现的 Bad Case

1. 模型把“相关专业优先”放进了硬门槛列表，但“优先”不是强制条件。
2. 模型把“画像没有提供证据”写成“缺乏”或“不熟悉”，结论强度过高。

两条问题已经写入提示词约束。后续评测需要检查它们是否复现。

## 当前结论

API、V4 Pro 模型、JSON 输出和本地证据校验均已跑通。系统已经从离线规则原型升级为可调用真实模型的单智能体核心，但在加入脱敏简历并完成语义回归测试前，不应宣称达到可直接投递的质量。
