## 2026-08-15：工具清单不能推导为熟练掌握

- 发现：模型根据简历技能栏中的 Python、SQL，生成了“熟练使用”的优势表述。
- 人工事实：用户此前确认 Python 水平为入门。
- 决策：优势表述不得使用“熟练、精通、擅长、能力较强”等未经直接证据支持的强度词。
- 影响：将此规则加入匹配结果的程序校验和自动测试。

## 2026-08-15：简历建议不得创造待补事实

- 发现：模型改用“掌握”描述工具水平，并建议量化未提供原始记录的项目成果、向当前简历补充不存在的 RAG 经历。
- 决策：能力强度同义词同样拦截；量化建议必须明确限定为已有可核验记录；已确认不存在的经历只能列为未来学习任务，不能列为当前简历修改建议。
- 影响：校验覆盖摘要、优势、简历建议和下一步行动四个区域。

## 2026-08-18：公开看板使用会话状态与 CSV，不使用共享 SQLite

- 场景：CareerPilot 部署在公开 Streamlit 服务，多个访客可能使用同一进程。
- 决策：投递记录仅写入浏览器会话；长期保存使用用户主动下载和导入的 CSV。
- 原因：在没有用户身份与行级权限前，共享 SQLite 可能造成跨访客求职数据泄露。
- 安全：CSV 导出会中和可能被电子表格当作公式执行的开头字符。
