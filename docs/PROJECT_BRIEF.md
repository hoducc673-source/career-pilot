# CareerPilot 项目需求说明 v0.1

## 1. 用户背景

- 身份：金融学专业大四学生
- 当前状态：对互联网、经济和金融相关岗位感兴趣，但目标岗位尚未确定
- 技术基础：Python 入门，暂未使用过 Git 和命令行
- 预算：每月不超过 500 元人民币
- 数据授权：愿意使用个人简历，开发阶段优先使用脱敏版本
- 主要使用地区：中国大陆
- 模型策略：保持供应商可替换；首选离线基线，模型阶段拟接入 DeepSeek API

## 2. 要解决的问题

用户目前的首要问题不是“如何润色某个岗位的简历”，而是：

1. 哪些岗位方向值得优先了解？
2. 用户已有经历能支持哪些方向？
3. 哪些判断仍缺少证据？
4. 如何通过低成本的小任务验证兴趣和适配度？
5. 方向确定后，如何针对真实 JD 修改材料并准备面试？

## 3. 产品定位

CareerPilot 是一个基于证据的职业探索与求职辅助智能体。它不替用户做职业决定，也不把模型输出包装成权威测评，而是帮助用户完成“提出候选方向—收集证据—设计验证实验—复盘—进入求职执行”的闭环。

## 4. MVP 范围

### 必须实现

- 读取结构化职业偏好问卷
- 输出 3 个优先探索方向
- 每个方向展示支持证据、风险和 7 天验证任务
- 分数计算透明、可测试
- 无 API Key 时也能演示
- 不编造用户经历

### 暂不实现

- 自动投递简历
- 自动登录招聘网站或批量爬取
- 多智能体协作
- 长期记忆和云数据库
- 复杂 Web 界面
- 用单一匹配分数替代人的判断

## 5. 后续完整流程

```text
职业偏好与经历
      ↓
候选方向与验证实验
      ↓ 人工选择
真实岗位 JD 集合
      ↓
岗位要求结构化提取
      ↓
简历证据匹配与缺口分析
      ↓ 人工确认
材料修改、面试准备、投递跟踪
```

## 6. MVP 验收标准

- 示例问卷可以通过一条命令生成报告
- 输出至少包含 3 个候选方向
- 每个方向至少有 2 条解释和 1 个行动实验
- 相同输入得到稳定结果
- 自动测试覆盖排序、数量和主要字段
- 缺少或非法输入时给出可理解的错误提示
- 项目中不存在真实 API Key 或未脱敏简历

## 7. 成功指标

项目层面：用户能独立解释数据从哪里进入、如何被处理、为什么产生结果，以及如何用测试检查结果。

使用层面：两周内完成至少 2 个方向验证实验，并收集至少 6 条真实 JD，从“泛泛迷茫”推进到“有证据地保留 2～3 个方向”。

## 8. 当前职业偏好证据

- 沟通与协作：4/5
- 学习编程和数字工具的意愿：5/5
- 客户沟通、说服与业绩压力接受度：4/5
- 数据分析、细节规范、研究整理、不确定性接受度：均为 3/5，暂时缺少足够证据

因此第一轮应优先比较“数据/工具导向”和“沟通/业务导向”的岗位，而不是直接断言某个职业最适合。
