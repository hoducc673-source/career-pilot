# CareerPilot RAG 最小学习项目

状态：最小版本已完成——11 个检索评测案例通过，向量检索为可选升级
适合水平：Python 入门
原则：完成并通过测试前，不把 RAG 写入简历

## 1. 项目目标

为 CareerPilot 增加一个“项目知识问答”功能：用户提出问题后，系统先从本地文档中找出最相关的原文片段，再把片段交给 DeepSeek V4 Pro 生成答案，并附上来源。

首版问答范围包括项目规则、岗位字段定义、当前开发阶段和隐私边界。评测问题不直接写入知识库，避免检索器只记住题目文本。

## 2. 为什么这是 RAG

RAG 是“检索增强生成”：

1. Retrieval：从知识库检索相关片段。
2. Augmentation：把检索结果加入模型上下文。
3. Generation：模型只基于这些上下文生成答案。

第一版不使用复杂向量数据库。先用可解释的关键词检索跑通流程，理解每一步后，再决定是否增加向量检索。

## 3. 知识库范围

第一版只读取以下非敏感文件：

- `docs/PROJECT_BRIEF.md`
- `docs/CAREERPILOT_PRD_V0.1.md`
- `docs/JD_SCHEMA.md`
- `docs/ROADMAP.md`
- `docs/RAG_MINI_PROJECT_PLAN.md`
- `README.md`

私有简历、API Key 和个人画像不进入 RAG 知识库。

## 4. 实现步骤

### 第一步：文档切片

按 Markdown 标题和段落把文档拆成小片段，为每段生成稳定编号、来源文件和标题。

验收：没有空片段；每段都能追溯到文件；相同输入产生相同编号。

### 第二步：可解释检索

对问题和片段进行中英文关键词匹配，返回得分最高的 3～5 个片段。

验收：询问“硬门槛”时能检索到 JD 或 PRD 中的相关定义；检索结果显示得分和来源。

### 第三步：带上下文生成

把检索片段发送给 DeepSeek V4 Pro，要求只依据片段回答；找不到依据时返回“知识库没有足够证据”。

验收：答案必须包含片段编号；不得引用未检索到的内容。

### 第四步：评测

建立至少 10 个问题，覆盖正确检索、无答案、错误引用和提示词注入。

验收：引用合法率 100%；无依据问题不编造答案；私有文件不会被加载。
